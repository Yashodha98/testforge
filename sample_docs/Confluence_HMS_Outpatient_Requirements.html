HMS Release 4.2 - Outpatient Module - Requirements

This page describes the outpatient registration and appointment features for the Hospital Management System (HMS) release 4.2. Users: front-desk receptionists and patients using the mobile app. Owner: Product Owner, Outpatient. Status: Approved for Sprint 18.

US-101 Register a new patient

As a front-desk receptionist, I want to register a new patient, so that the patient can be booked for consultations and billed correctly.

Acceptance Criteria

  • Given the receptionist is on the New Patient screen, when all mandatory fields are completed and Save is clicked, then a unique Medical Record Number (MRN) is generated and shown within 2 seconds.
  • The patient full name must be between 2 and 60 characters.
  • Age is calculated from the date of birth and must be between 0 and 120 years; a future date of birth is rejected.
  • The National ID / Iqama number must be exactly 10 digits and start with 1 or 2.
  • When a patient with the same National ID already exists, the message "Patient already registered" is shown and the existing MRN is displayed.

US-102 Book an outpatient appointment

As a patient using the hospital mobile app, I want to book an appointment with a doctor, so that I can be seen without calling the hospital.

Acceptance Criteria

  • Available 15-minute slots for the selected doctor and date are displayed, and booked slots cannot be selected.
  • Appointments can be booked up to 30 days in advance; past dates cannot be selected.
  • A patient can have a maximum of 3 active appointments; booking a 4th shows "You already have 3 active appointments".
  • After booking, a confirmation with doctor, date, time and booking reference is displayed and an SMS is sent.

US-103 Cancel an appointment

As a patient, I want to cancel my appointment in the app, so that the slot can be given to another patient.

Acceptance Criteria

  • Cancellation is allowed only at least 2 hours before the appointment time.
  • Within 2 hours of the appointment the message "Please contact the clinic to cancel" is shown and the Cancel button is disabled.
  • After cancellation the slot becomes available again immediately and a cancellation SMS is sent.
